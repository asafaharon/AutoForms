💻 API Examples

GET /api/templates/contact_basic/use-with-submissions

{
  "form_id": "abc123",
  "html": "<form action='/api/submissions/submit/abc123' method='POST'>...",
  "submission_url": "https://your-domain.com/api/submissions/submit/abc123",
  "embed_code": "<!-- Ready-to-embed code -->",
  "iframe_code": "<iframe src='/embed/abc123'>..."
}

POST /api/submissions/submit/{form_id}

curl -X POST "https://your-domain.com/api/submissions/submit/abc123" \
  -d "name=John+Doe&email=john@example.com&message=Hello"
